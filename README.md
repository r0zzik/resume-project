# Резюме студента

Учебный проект — интерактивное резюме с возможностью заполнения и печати.

## Что реализовано

- 5 разделов: «О себе», «Контакты», «Навыки», «Опыт», «Итоговое резюме»
- Переключение разделов без перезагрузки страницы
- Кастомный выпадающий список с автокомплитом (город, тип контакта)
- Добавление и удаление строк контактов
- Выбор навыков с уровнями: начальный, средний, продвинутый (не более 5)
- Загрузка фото с предпросмотром
- Сохранение данных в итоговое резюме
- Сохранение резюме в PDF (печать только нужного блока)
- Адаптивная вёрстка (1024px, 768px, 480px)
- Анимация при переключении разделов
- БЭМ-нейминг

## Стек

- HTML5
- CSS (Flexbox, Grid)
- JavaScript (DOM, события, FileReader)

## Как запустить

Открыть index.html в браузере или через Live Server.

# Резюме студента

Учебный проект — интерактивное резюме с возможностью заполнения и печати.

## Что реализовано

- 5 разделов: «О себе», «Контакты», «Навыки», «Опыт», «Итоговое резюме»
- Переключение разделов без перезагрузки страницы
- Пошаговая навигация между разделами (кнопки "назад" и "Далее")
- Кастомный выпадающий список с автокомплитом (город, тип контакта)
- Добавление и удаление строк контактов
- Выбор навыков с уровнями: начальный, средний, продвинутый (не более 5)
- Загрузка фото с предпросмотром (FileReader API)
- Сохранение данных в итоговое резюме и в localStorage, а также выборочная или полная очистка
- Экспорт резюме в PDF (печать только нужного блока)
- Адаптивная вёрстка под десктопы. планшеты и смартфоны, мобильное бургер-меню
- Анимация при переключении разделов
- БЭМ-нейминг

## Стек

- HTML5 (семантическая вёрстка, БЭМ)
- CSS (Flexbox, Grid, адаптивная верстка, CSS-анимации)
- JavaScript (DOM, события, FileReader, localStorage)

## Как запустить

Открыть index.html в браузере или через Live Server.
